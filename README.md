# 🐱 Purrductivity

A minimal cat-themed todo list app. Add tasks, abandon them when done — your purr-sonal task manager.

> **Demo note:** Marking tasks as complete is intentionally absent. This feature is implemented live as part of a coding agent demo.

## Tech stack

- [Vite 6](https://vite.dev) + [React 19](https://react.dev) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [Vitest](https://vitest.dev) + [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)

## Getting started

```bash
npm install
npm run dev
```

## Testing

```bash
npm test           # run once
npm run test:watch # watch mode
```
